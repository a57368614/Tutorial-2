# Repair Demo｜報修圖片上傳

這是一個可直接在本機執行的設備報修展示程式。報修者可提交案件並選擇性附上單張 JPG、PNG 或 GIF 圖片；管理案件頁可查看文字紀錄與圖片。

## 快速開始

需求：Python 3.10 以上，不需安裝額外套件。

在此資料夾開啟終端機並執行：

```powershell
python app.py
```

然後用瀏覽器開啟 <http://127.0.0.1:8000>。停止服務請回到終端機按 `Ctrl+C`。

## 使用方式

1. 在「報修首頁」填寫設備／問題標題及問題描述；地點、聯絡人和圖片可選填。
2. 選擇一張 JPG、PNG 或 GIF 圖片。頁面會顯示預覽，並先檢查格式和 5 MB 大小限制。
3. 按「送出報修單」。案件編號與最新紀錄會顯示在畫面上。
4. 開啟「管理案件」查看所有案件和圖片；沒有附圖的案件會標示「未附圖片」。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `app.py` | 本機 HTTP 伺服器、案件 API、圖片驗證與儲存 |
| `templates/index.html` | 報修表單、首頁及案件管理頁面 |
| `static/app.js` | 表單檢查、圖片預覽、FormData 送出與最新案件 |
| `static/admin.js` | 管理案件列表及圖片預覽 |
| `static/styles.css` | 響應式頁面樣式 |
| `software-spec.md` | 功能需求、資料流、驗收條件及實作紀錄 |
| `AGENTS.md` | 此專案的 Agent 工作規則 |
| `skills/repair-image-upload/SKILL.md` | 報修圖片上傳任務的可重用處理方法 |

## 資料位置與限制

- 案件資料寫入 `data/tickets.json`。
- 圖片寫入 `uploads/`，並使用隨機產生的檔名；原始上傳檔名不會用作儲存路徑。
- 支援 JPG、PNG、GIF，單張圖片上限 5 MB；不支援多圖上傳。
- 這是教學展示程式，管理頁沒有登入驗證，不應直接部署到公開網路。
- 若要清除展示資料，先停止伺服器，再刪除 `data/tickets.json` 和 `uploads/` 中的圖片。

## 驗收紀錄

後端提交流程已依 `software-spec.md` 驗收合法圖片、無圖片、不支援格式及超過大小限制。此工作環境的瀏覽器安全規則不允許開啟本機檔案頁，隔離環境也無法連線至本機伺服器，因此管理頁的瀏覽器畫面尚未擷取。啟動程式後可依 `screenshots/README.md` 補上作業要求的畫面。
